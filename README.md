# Green-api-test

React-интерфейс для отправки и получения текстовых сообщений в Telegram через [GREEN-API](https://green-api.com/).

## Разработка

Для запуска приложения в режиме разработки:

1. Установить зависимости `npm install`
2. Запустить сервер `npm run dev`
3. Открыть http://localhost:3100

На странице входа указать `idInstance` и `apiTokenInstance` из кабинета GREEN-API.
